# Changelog

## [1.0.0] - 2026-08-01
### Added
- Complete Student Authentication (Signup, Login, Logout).
- Complete Teacher Authentication (Signup, Login, Logout).
- Session Management for Teachers.
- Attendance Marking for Students with Device Fingerprinting.
- Device Approval System for Teachers.
- Attendance Reports and Analytics for both roles.
- Profile management with real-time statistics.
- Auto-login and session restoration.
- Modern UI with Light/Dark theme support.
